StoryKeeper поддерживает PlaceholderAPI.
### Плейсхолдеры
Созданы аналогично [командам для администраторов](../Usage/commands#для-администраторов)  
`%StoryKeep_msnset_<миссия>_<состояние>%` - Выдает состояние. Имя игрока не обязательно, уже заложено в плейсхолдеры  
`%StoryKeep_msnget_<миссия>%` - Получает состояние
