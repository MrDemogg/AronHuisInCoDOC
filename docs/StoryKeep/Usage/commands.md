# Команды

### Общедоступные
`/openMission` - открывает книгу с описанием миссии игроку с помощью токена. Но использование игроками или даже админами не предусмотрено из-за ряда причин. Это команда - лишь необходимость для плагина.  
`/openMissions` - открывает игроку его список миссий.
### Для администраторов
`/msnset <player_name> <mission> <state>` - изменение состояния (или создает) миссии у игрока  
`/msnget <player_name> <mission>` - получение состояния миссии у игрока.  
**Выдаст "no" в случае, если миссии нет вообще** в списке у игрока  
- player_name - имя игрока
- mission - миссия
- state - [состояние](config#states)
