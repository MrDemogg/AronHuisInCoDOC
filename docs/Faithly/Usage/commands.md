# Команды
Команда в плагине одна: /religion  
По умолчанию сама по себе доступна всем, но не все её параметры доступны всем.

### Общедоступные параметры (по умолчанию)
`/religion atheism/islam/hinduism/christianity` - данные религии генерируются плагином автоматически (но могут быть убраны из config.yml) и не имеют физического владельца, поэтому примкнуть к ним можно напрямую этой командой.
`/religion <religion_name> create` - создает религию (ТРЕБУЕТСЯ наличие в руке предмета, на который "запишется" религия, в количестве 1 штука, иначе не сработает)
`/religion <religion_name> <block/allow> <words/item/blocks> <values>` - изменяет правила религии: 
- block/allow - запретить/разрешить
- words/item/blocks - тип (слова, предмет, блок)
- values - значения. Слова могут быть записаны <b>в большом количестве РАЗОМ, через пробел</b> (например "сука блять шлюха уёбище", в список пойдут все 4 слова). Предметы и блоки можно записывать <b>по 1 штуке за раз</b>
### Для администраторов
`/religion reload` - перезагружает плагин
