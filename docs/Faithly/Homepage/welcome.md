# Get Started (Введение)
Faithly - это плагин позволяющий создавать кастомные религии на сервере

Плагин достаточно прост в освоении и настройке. Создавался для [MAGMA RPG](https://www.youtube.com/watch?v=dQw4w9WgXcQ) (изначально в качестве шутки)  

Под версию 1.21 и выше, возможно может быть запущен на 1.20 или 1.19, но не проверено
